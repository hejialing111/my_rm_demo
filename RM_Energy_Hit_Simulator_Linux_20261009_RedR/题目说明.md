# 能量机关击打测试题目

## 任务目标

基于仿真提供的实时相机图像、相机内外参、目标物理尺寸及弹道参数，自主完成能量机关的识别、位姿解算、运动估计与预测、弹道解算和云台控制，通过发布 yaw、pitch 与开火指令实现有效击打。可使用 C++ 或 Python 实现算法，不限定识别方法、特征点选择或算法框架。

## 运行状态与难度

选择要击打的能量机关运行状态，按难度由低到高分为三档：

| 运行状态 | 运动特点 | 主要考察能力 | 得分权重 |
| --- | --- | --- | --- |
| 静止 | 目标保持当前位置，不旋转 | 识别、测距、坐标转换、弹道解算与瞄准控制 | 基础权重 |
| 匀速旋转 | 目标以恒定角速度旋转 | 在基础能力上完成运动跟踪、飞行时间补偿与提前量预测 | 高于静止档 |
| 周期旋转 | 目标角速度按三角函数周期变化 | 在基础能力上完成运动参数拟合、变速预测及延迟补偿 | 最高权重 |

按 **R** 可循环切换运行状态，顺序为“周期旋转 → 静止 → 匀速旋转 → 周期旋转”。具体运动公式、参数范围与接口定义见随附 README 和参数文件。三档难度依次上升，评价时对应的得分权重依次提高；具体数值权重由测试组织方统一公布，不在本文中预设。

## 有效击打规则

同时最多有两块待击打靶面亮起。只有弹丸命中当前亮起且可击打靶面的有效圆形区域，才计为有效命中并切换靶面状态。击中未亮起的靶面、扇叶其他部分、中心 R 标志或其他场景物体均不计为有效命中。

需根据弹丸飞行时间和系统延迟预测到达时刻的目标位置，而非仅瞄准当前图像中的位置。目标状态切换后，应重新选择有效目标并保持稳定跟踪。

## 结果评价

综合命中率与算法效率评估结果，并结合所选运行状态的难度权重。命中率为“有效命中数 ÷ 实际发射弹丸数”；尚未发射时不作为有效成绩。效率关注识别与解算耗时、控制更新频率、端到端响应延迟及资源占用。高频无效开火或仅靠降低发射次数获得高命中率，不应代替稳定、持续的有效击打能力。

各档成绩分别记录运行状态、测试时长、发射数、命中数、命中率及算法效率指标。对比测试应使用一致的相机位置、物理参数与测试条件，避免人工操作改变测试结果。
